# Data

WM-811K dataset is NOT included in this repository.

## Download
1. https://www.kaggle.com/datasets/qingyi/wm811k-wafer-map
2. Place LSWMD.pkl in this directory

## Structure after download
- LSWMD.pkl — 811,457 wafer maps with metadata
- df_labeled: 172,950 samples (failureType labeled)
- df_unlabeled: 638,507 samples
